**Java LeetCode ACM 模式 万能样板框架合集（纯手动构建版）**

我一次性给你整理了 **8 个最常用类型** 的完整、可直接复制的 ACM 模板。  
全部采用 **手动构建** 风格（一个个 `new`），没有额外辅助函数，方便你直接改成任何题目。  
每个模板都包含：
- 多个注释好的测试用例（不同长度、空、边界）
- `fun()` 函数占位（你只改这里）
- 打印/输出语句
- 节点定义（链表/树直接复制粘贴）

### 8. 动态规划（DP）通用模板（1D + 2D）
```java
public class Main {
    public static void main(String[] args) {
        // 示例 1 - 1D DP 常用

        int result = fun(nums);
        System.out.println(result);
    }
    
    public static int fun(int[] nums) {
        int n = nums.length;
        if (n == 0) return 0;
        
        // 1D DP 示例
        int[] dp = new int[n];
        // dp[0] = ...;
        
        // 2D DP 时改成：
        // int m = matrix.length, n = matrix[0].length;
        // int[][] dp = new int[m][n];
        
        // 这里写你的 DP 转移方程
        return dp[n-1];
    }
}
```
